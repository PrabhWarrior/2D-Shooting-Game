# 2D Shooting Game

A simple browser shooter built with plain HTML, CSS and JavaScript on a canvas.

**▶ Play it live:** https://prabhwarrior.github.io/2D-Shooting-Game/

## How to play

- Pick a difficulty (Easy, Medium, Hard, Insane) and press **Play**.
- Click anywhere to shoot toward the cursor.
- Big balls shrink when hit (+10), small balls are destroyed (+25).
- The game ends when a ball reaches you.

## Run locally

Open `index.html` in a browser. No build step or dependencies needed.
